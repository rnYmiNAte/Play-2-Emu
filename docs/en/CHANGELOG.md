# Play2 Emu Changelog

---

## Version 1.0.0 (January 8, 2026)
- Initial release for Android and iOS
- Supported formats: `.chd`, `.bin/.cue`, `.iso`
- Rendering backends: OpenGL (Android/iOS), Vulkan (Android), Metal (iOS)
- Minimum OS support: Android 4.0, iOS 5

## Version 0.9.0 (December 15, 2025)
- Beta release for Android only
- Added `.chd` format support
- Implemented frame sync for NTSC/PAL standards

## Version 0.8.0 (November 5, 2025)
- Alpha release with basic `.iso` support
- OpenGL ES rendering backend only
