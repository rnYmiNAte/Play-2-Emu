# 故障排除指南

---

## 常见问题及解决方案

### 问题 1：应用无法检测到 BIOS 文件
- **症状**：启动时显示“未找到有效 BIOS”提示
- **原因**：BIOS 文件路径错误、文件名不正确或文件损坏
- **解决方案**：
  1. 确认 BIOS 文件名为 `ps2_bios.bin`、`scph10000.bin` 等支持的名称
  2. 将文件放置在指定路径：
     - Android：`内部存储/Play2Emu/bios/`
     - iOS：通过应用内文件选择器导入
  3. 检查文件完整性（确保从合法渠道获取且未损坏）

### 问题 2：游戏运行卡顿或帧率过低
- **症状**：画面不流畅，帧率低于 25/29.97 fps
- **原因**：硬件性能不足、渲染设置过高或后台应用占用资源
- **解决方案**：
  1. 关闭其他后台运行的应用
  2. 进入设置降低渲染质量：
     - 切换到 OpenGL 后端（Vulkan 可能对旧设备压力较大）
     - 关闭额外的图形优化选项
  3. 确保设备满足推荐配置（骁龙 625 或苹果 A9 及以上）
