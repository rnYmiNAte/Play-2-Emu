# Play2 Emu Security Policy

---

## Supported Versions
We provide security updates for the following versions:
| Version | Supported          |
|---------|--------------------|
| 1.0.x   | ✅ Yes             |
| 0.9.x   | ❌ No              |
| < 0.9   | ❌ No              |

---

## Reporting a Vulnerability
- **Do NOT open a public GitHub issue** – this could expose users to risk
- Send details to security@ampplay.com with:
  - Emulator version and platform (Android/iOS)
  - Description of the vulnerability and how to reproduce it
  - Potential impact on users
- We will respond within 48 hours and provide a timeline for a fix
- If the vulnerability is confirmed, we will credit you in the release notes (with your permission)

---

## Security Best Practices for Users
- Only download the app from official sources (GitHub Releases, authorized app stores)
- Do not install modified or "cracked" versions of the emulator
- Keep your device’s OS and the emulator updated to the latest version
- Only use BIOS files from your own physical PS2 console
- Avoid loading disc images from untrusted sources (they may contain malware)
